Les mots pour parler des émotions

Cette partie présente les principaux termes utilisés pour décrire les émotions, les ressentis, l'humeur et les réactions émotionnelles. Ces notions sont fréquemment abordées lors d'une consultation psychologique.

❤️ 2.1 L'émotion

🔎 Définition

Une émotion est une réaction psychologique et physiologique qui apparaît en réponse à une situation, un événement, une pensée ou une perception.

Les émotions peuvent influencer :

  • les pensées ;
  • le comportement ;
  • les réactions physiques ;
  • les décisions ;
  • les relations avec les autres.

🧠 Exemples d'émotions

  • joie ;
  • tristesse ;
  • peur ;
  • colère ;
  • surprise ;
  • dégoût.

Les émotions peuvent être agréables, désagréables ou complexes.

📌 À retenir

Une émotion est une réaction temporaire impliquant le corps, les pensées et le comportement.

💭 2.2 Le ressenti

🔎 Définition

Le ressenti correspond à la manière subjective dont une personne vit intérieurement une situation.

Deux personnes vivant exactement le même événement peuvent avoir des ressentis très différents.

🧠 Exemple

Face à une prise de parole devant un groupe :

  • une personne peut ressentir de l'excitation ;
  • une autre peut ressentir de la peur ;
  • une autre peut ressentir de l'indifférence.

📌 À retenir

Le ressenti correspond à l'expérience personnelle et subjective d'une situation.

🌡️ 2.3 L'humeur

🔎 Définition

L'humeur correspond à un état émotionnel général qui peut durer plus longtemps qu'une émotion ponctuelle.

Elle influence la manière dont une personne perçoit :

  • son environnement ;
  • les événements ;
  • les autres ;
  • elle-même.

🧠 Exemples

Une humeur peut être :

  • positive ;
  • triste ;
  • irritable ;
  • anxieuse ;
  • stable ;
  • fluctuante.

📌 À retenir

Émotion → généralement ponctuelle et liée à une situation.

Humeur → état émotionnel plus durable et général.

😰 2.4 L'anxiété

🔎 Définition

L'anxiété correspond à un état d'inquiétude, de tension ou d'appréhension face à une menace réelle ou anticipée.

Elle peut être normale dans certaines situations.

Elle devient plus problématique lorsqu'elle est :

  • excessive ;
  • fréquente ;
  • difficile à contrôler ;
  • source de souffrance ;
  • responsable de difficultés dans la vie quotidienne.

🧠 Manifestations possibles

💭 Psychologiques

  • inquiétude ;
  • anticipation négative ;
  • peur ;
  • difficultés de concentration.

🫀 Physiques

  • accélération du rythme cardiaque ;
  • tensions musculaires ;
  • transpiration ;
  • tremblements ;
  • sensation d'oppression.

📌 À retenir

L'anxiété est une réaction normale face à une menace, mais elle peut devenir problématique lorsqu'elle devient excessive ou persistante.

⚡ 2.5 Le stress

🔎 Définition

Le stress est une réponse psychologique et physiologique face à une situation perçue comme exigeante, difficile ou menaçante.

🧠 Manifestations possibles

  • accélération du rythme cardiaque ;
  • tension musculaire ;
  • inquiétude ;
  • irritabilité ;
  • difficultés de concentration ;
  • fatigue.

🧬 Stress aigu et chronique

Stress aigu

Réaction temporaire face à une situation précise.

Stress chronique

État de stress qui persiste sur une longue période.

📌 À retenir

Le stress correspond à une réponse d'adaptation face à une situation perçue comme exigeante.

😡 2.6 La colère

🔎 Définition

La colère est une émotion pouvant apparaître lorsqu'une personne perçoit :

  • une injustice ;
  • une frustration ;
  • une menace ;
  • une violation de ses limites ;
  • un obstacle.

🧠 Manifestations possibles

  • irritation ;
  • tension ;
  • augmentation de l'énergie ;
  • envie de protester ;
  • comportements impulsifs.

📌 À retenir

La colère est une émotion normale. Ce sont principalement son intensité, sa fréquence et la manière dont elle est exprimée qui peuvent parfois poser problème.

😤 2.7 La frustration

🔎 Définition

La frustration apparaît lorsqu'un objectif, un besoin ou un désir est empêché ou difficile à satisfaire.

🧠 Exemple

Une personne souhaite obtenir quelque chose mais rencontre constamment des obstacles.

Elle peut ressentir :

  • irritation ;
  • impatience ;
  • colère ;
  • découragement.

📌 À retenir

La frustration correspond à une réaction émotionnelle face à un obstacle ou à une impossibilité d'obtenir ce qui est souhaité.

😔 2.8 La tristesse

🔎 Définition

La tristesse est une émotion généralement associée à :

  • une perte ;
  • une déception ;
  • une séparation ;
  • un échec ;
  • une situation difficile.

🧠 Manifestations possibles

  • baisse d'énergie ;
  • envie de s'isoler ;
  • pleurs ;
  • ralentissement ;
  • diminution temporaire de la motivation.

📌 À retenir

La tristesse est une émotion humaine normale et ne correspond pas automatiquement à une dépression.

😨 2.9 La peur

🔎 Définition

La peur est une émotion liée à la perception d'un danger ou d'une menace.

Elle prépare l'organisme à réagir.

🧠 Réactions possibles

Face à un danger, l'organisme peut notamment :

  • fuir ;
  • combattre ;
  • se figer.

Ces réactions sont parfois appelées :

Fight → combattre

Flight → fuir

Freeze → se figer

📌 À retenir

La peur est une réaction adaptative permettant d'identifier et de réagir à une menace.

😳 2.10 La honte

🔎 Définition

La honte est une émotion liée à une perception négative de soi-même.

Elle peut apparaître lorsqu'une personne pense avoir :

  • échoué ;
  • été humiliée ;
  • fait quelque chose de mal ;
  • perdu sa valeur aux yeux des autres.

🧠 Différence avec la culpabilité

Honte → « Je suis une mauvaise personne. »

Culpabilité → « J'ai fait quelque chose que je regrette. »

La honte concerne davantage l'image de soi, tandis que la culpabilité concerne davantage une action ou un comportement.

📌 À retenir

La honte implique généralement une évaluation négative de soi-même.

⚖️ 2.11 La culpabilité

🔎 Définition

La culpabilité apparaît lorsqu'une personne pense avoir fait quelque chose de mauvais, injuste ou contraire à ses valeurs.

🧠 Manifestations possibles

  • regrets ;
  • pensées répétitives sur une action ;
  • besoin de réparer ;
  • tristesse ;
  • anxiété.

📌 À retenir

La culpabilité est principalement liée à ce qu'une personne pense avoir fait, contrairement à la honte qui concerne davantage la perception de soi.

😖 2.12 L'irritabilité

🔎 Définition

L'irritabilité correspond à une tendance à réagir plus facilement ou plus intensément à des situations habituellement supportables.

🧠 Manifestations possibles

  • impatience ;
  • réactions de colère ;
  • faible tolérance à la frustration ;
  • tensions relationnelles ;
  • sensibilité aux stimulations.

🧬 Facteurs possibles

Elle peut être influencée par :

  • fatigue ;
  • stress ;
  • manque de sommeil ;
  • douleur ;
  • anxiété ;
  • certaines situations médicales ou psychologiques.

📌 À retenir

L'irritabilité correspond à une augmentation de la sensibilité aux frustrations et aux stimulations.

😵 2.13 Le sentiment de surcharge

🔎 Définition

Le sentiment de surcharge correspond à l'impression d'avoir trop de choses à gérer par rapport à ses capacités ou ressources disponibles à un moment donné.

🧠 Manifestations possibles

  • impression d'être dépassé ;
  • difficulté à organiser ses tâches ;
  • fatigue mentale ;
  • irritabilité ;
  • stress ;
  • difficultés de concentration.

📌 À retenir

Le sentiment de surcharge apparaît lorsqu'une personne perçoit un déséquilibre entre les demandes et ses ressources disponibles.

🫥 2.14 L'engourdissement émotionnel

🔎 Définition

L'engourdissement émotionnel correspond à une diminution temporaire ou persistante de la capacité à ressentir certaines émotions.

Une personne peut avoir l'impression :

« Je sais ce qui se passe, mais je ne ressens presque rien. »

🧠 Manifestations possibles

  • impression de vide ;
  • diminution des émotions ;
  • difficulté à ressentir du plaisir ;
  • détachement émotionnel ;
  • sensation d'être distant.

🧬 Contextes possibles

Il peut notamment apparaître dans certains contextes :

  • stress important ;
  • traumatisme ;
  • épuisement ;
  • dépression ;
  • dissociation.

📌 À retenir

L'engourdissement émotionnel décrit une diminution du ressenti émotionnel, dont les causes peuvent être différentes.

🌊 2.15 La régulation émotionnelle

🔎 Définition

La régulation émotionnelle correspond à la capacité à reconnaître, comprendre et gérer ses réactions émotionnelles.

Elle ne consiste pas à supprimer toutes les émotions.

🧠 Elle peut comprendre

  • identifier une émotion ;
  • comprendre son origine ;
  • accepter sa présence ;
  • choisir comment réagir ;
  • diminuer une réaction trop intense si nécessaire.

🧩 Exemple

Une personne peut ressentir une forte colère mais décider de :

  1. prendre du recul ;
  2. attendre avant de répondre ;
  3. comprendre ce qui a déclenché la colère ;
  4. exprimer son désaccord sans agressivité.

📌 À retenir

La régulation émotionnelle consiste à gérer ses émotions sans nécessairement chercher à les supprimer.

🧠 2.16 L'ambivalence émotionnelle

🔎 Définition

L'ambivalence émotionnelle correspond à la présence simultanée de sentiments ou d'émotions contradictoires envers une même situation, personne ou décision.

🧠 Exemple

Une personne peut être :

  • heureuse de commencer un nouveau travail ;
  • mais également anxieuse à l'idée du changement.

Les deux émotions peuvent exister en même temps.

📌 À retenir

Ressentir plusieurs émotions contradictoires simultanément est possible et relativement courant.

❤️‍🩹 2.17 La détresse émotionnelle

🔎 Définition

La détresse émotionnelle désigne un état de souffrance psychologique important.

Elle peut être associée à différentes émotions :

  • tristesse ;
  • anxiété ;
  • peur ;
  • désespoir ;
  • colère ;
  • sentiment d'impuissance.

🧠 Manifestations possibles

  • pleurs ;
  • agitation ;
  • retrait social ;
  • difficultés à réfléchir ;
  • troubles du sommeil ;
  • difficultés à fonctionner normalement.

📌 À retenir

La détresse émotionnelle décrit un niveau important de souffrance psychologique, sans désigner à elle seule un trouble précis.

🧠 À RETENIR PARTIE 2

Les émotions jouent un rôle important dans le fonctionnement humain.

Elles peuvent influencer :

🧠 Les pensées

❤️ Le comportement

🫀 Les réactions physiques

👥 Les relations

🎯 Les décisions

Une émotion n'est pas automatiquement bonne ou mauvaise.

Même une émotion désagréable peut avoir une fonction :

😨 La peur → peut signaler un danger

😡 La colère → peut signaler une injustice ou une limite dépassée

😔 La tristesse → peut apparaître après une perte

⚡ Le stress → prépare l'organisme à faire face à une demande

🧩 L'objectif en psychologie n'est généralement pas de supprimer toutes les émotions, mais de mieux les comprendre et d'apprendre à y répondre de manière adaptée.
