Phénomènes psychologiques

Les phénomènes de la perception

La perception permet au cerveau de sélectionner, organiser et interpréter les informations provenant des sens. Elle ne correspond cependant pas toujours à une reproduction exacte de la réalité.

Le cerveau utilise en permanence les informations sensorielles, l'attention, la mémoire, les attentes et le contexte pour construire une représentation cohérente de ce qui est perçu.

Cette partie présente différents phénomènes pouvant modifier, compléter ou influencer cette construction perceptive.

1.1 La perception

La perception désigne le processus par lequel le cerveau reçoit, organise et interprète les informations provenant des sens.

Les informations sensorielles comprennent notamment :

  • La vision
  • L'audition
  • L'odorat
  • Le goût
  • Le toucher
  • La proprioception
  • Le système vestibulaire, impliqué notamment dans l'équilibre

La perception ne consiste donc pas simplement à « enregistrer » le monde extérieur.

Le cerveau sélectionne certaines informations, les compare avec des connaissances antérieures et leur donne une signification.

Exemple

Une même image peut être interprétée différemment selon le contexte dans lequel elle est présentée.

La perception dépend donc à la fois des informations provenant de l'environnement et de la manière dont le cerveau les traite.

1.2 La construction perceptive

Le cerveau reçoit une quantité extrêmement importante d'informations sensorielles.

Il est impossible de traiter consciemment chaque information avec la même précision.

La perception implique donc plusieurs opérations :

  • sélectionner les informations importantes ;
  • filtrer certaines informations ;
  • organiser les éléments perçus ;
  • comparer avec les connaissances déjà présentes ;
  • interpréter les informations ;
  • produire une représentation mentale cohérente.

Cette construction permet de fonctionner rapidement, mais elle peut également produire des erreurs perceptives.

1.3 Les illusions perceptives

Une illusion perceptive correspond à une interprétation incorrecte ou modifiée d'une information sensorielle réellement présente.

Contrairement à une hallucination, une illusion repose généralement sur un stimulus extérieur réel.

Exemple

Une ombre dans une pièce sombre peut être interprétée comme une personne.

L'objet ou la stimulation visuelle existe réellement, mais son interprétation est incorrecte.

Les illusions perceptives peuvent être influencées par :

  • la luminosité ;
  • le contexte ;
  • l'attention ;
  • les attentes ;
  • la fatigue ;
  • les émotions ;
  • les connaissances antérieures.

1.4 Les illusions visuelles

Les illusions visuelles sont des situations dans lesquelles ce qui est vu ne correspond pas exactement aux propriétés physiques du stimulus.

Elles peuvent concerner :

  • la taille ;
  • la longueur ;
  • la forme ;
  • la couleur ;
  • la profondeur ;
  • le mouvement ;
  • la position d'un objet.

Elles montrent que la vision est une construction active du cerveau.

Pourquoi sont-elles importantes ?

Les illusions permettent notamment d'étudier la manière dont le cerveau interprète les informations visuelles.

Elles sont utilisées dans la recherche en psychologie cognitive, en neurosciences et dans l'étude de la perception.

1.5 La pareidolie

La pareidolie correspond à la tendance à percevoir une forme ou un élément reconnaissable dans un stimulus ambigu ou aléatoire.

Le phénomène est particulièrement connu avec la perception de visages.

Exemples

Un visage peut sembler apparaître dans :

  • les nuages ;
  • une façade ;
  • une prise électrique ;
  • des taches ;
  • des ombres ;
  • des motifs naturels.

Le cerveau est particulièrement sensible aux configurations ressemblant à des visages.

La pareidolie n'est pas nécessairement pathologique.

Elle constitue un exemple de la manière dont le cerveau cherche spontanément à donner une structure et une signification aux informations perceptives.

1.6 Le phénomène McGurk

L'effet McGurk est un phénomène perceptif dans lequel ce qui est vu influence ce qui est entendu.

Lorsqu'un mouvement des lèvres correspond à un son différent de celui réellement présenté, le cerveau peut percevoir un troisième son.

Ce phénomène montre que

La perception de la parole ne dépend pas uniquement de l'audition.

Le cerveau combine notamment :

  • les informations auditives ;
  • les informations visuelles ;
  • le contexte ;
  • les connaissances linguistiques.

La perception est donc multimodale.

1.7 L'effet Stroop

L'effet Stroop correspond à une difficulté à nommer la couleur d'un mot lorsque le mot lui-même désigne une autre couleur.

Exemple

Le mot ROUGE peut être écrit avec une couleur différente.

La lecture automatique du mot entre alors en conflit avec la tâche consistant à nommer sa couleur.

Ce phénomène montre que certains traitements mentaux peuvent être automatiques et difficiles à inhiber.

Il est notamment utilisé pour étudier :

  • l'attention ;
  • l'inhibition ;
  • les interférences cognitives ;
  • le contrôle exécutif.

1.8 La cécité attentionnelle

La cécité attentionnelle correspond au fait de ne pas remarquer un stimulus pourtant visible lorsque l'attention est fortement concentrée sur une autre tâche.

Le stimulus peut être présent dans le champ visuel sans être consciemment identifié.

Exemple

Une personne concentrée sur le comptage d'éléments dans une scène peut ne pas remarquer un événement inhabituel qui se produit devant elle.

Ce phénomène montre que :

Voir quelque chose ne signifie pas nécessairement en avoir conscience.

L'attention joue donc un rôle majeur dans l'expérience perceptive.

1.9 La cécité au changement

La cécité au changement correspond à la difficulté à détecter une modification importante d'une scène visuelle lorsque cette modification survient dans certaines conditions.

Elle peut apparaître lorsque :

  • le changement est progressif ;
  • un élément visuel interrompt momentanément la scène ;
  • l'attention est dirigée ailleurs ;
  • plusieurs informations sont présentes simultanément.

Ce phénomène montre que la représentation consciente d'une scène visuelle est moins détaillée qu'elle peut sembler l'être.

1.10 L'attention sélective

L'attention sélective permet de concentrer les ressources mentales sur certaines informations plutôt que sur d'autres.

Elle joue un rôle essentiel dans la perception.

Exemple

Dans une pièce remplie de conversations, l'attention peut être dirigée vers une conversation particulière.

Cependant, certaines informations provenant de l'environnement peuvent continuer à être traitées en arrière-plan.

L'attention ne fonctionne donc pas nécessairement comme un simple interrupteur « activé ou désactivé ».

1.11 L'effet cocktail party

L'effet cocktail party désigne la capacité à suivre une conversation particulière dans un environnement sonore comprenant de nombreuses autres conversations.

L'attention permet de privilégier certaines informations auditives.

Cependant, des informations non directement suivies peuvent parfois attirer l'attention.

Exemple

Un prénom prononcé dans une autre conversation peut soudainement attirer l'attention.

Ce phénomène illustre la capacité du cerveau à sélectionner certaines informations parmi de nombreux stimuli concurrents.

1.12 L'hyperacousie

L'hyperacousie correspond à une sensibilité anormalement élevée à certains sons.

Des sons ordinaires peuvent alors être perçus comme particulièrement intenses ou difficiles à supporter.

L'hyperacousie peut avoir différentes causes et peut être associée à des problèmes auditifs, neurologiques ou à certains contextes cliniques.

Elle ne doit pas être confondue avec :

  • la misophonie ;
  • la phonophobie ;
  • une simple préférence pour le silence.

1.13 La misophonie

La misophonie correspond à une réaction émotionnelle ou comportementale particulièrement forte déclenchée par certains sons spécifiques.

Les sons déclencheurs peuvent notamment être liés :

  • à la mastication ;
  • à la respiration ;
  • aux claquements ;
  • à certains bruits répétitifs.

La réaction ne dépend pas nécessairement de l'intensité physique du son.

Un son relativement faible peut donc provoquer une réaction importante.

1.14 La synesthésie

La synesthésie désigne une expérience perceptive dans laquelle la stimulation d'un sens ou d'une modalité est associée de manière automatique à une expérience supplémentaire dans une autre modalité.

Exemples

Certaines personnes peuvent :

  • associer certaines lettres à des couleurs ;
  • associer certains sons à des couleurs ;
  • percevoir certaines formes lorsqu'elles entendent des sons ;
  • associer certains nombres à des positions spatiales.

La synesthésie peut être stable et automatique chez les personnes concernées.

Elle n'est pas considérée comme une maladie en elle-même.

1.15 La déréalisation

La déréalisation correspond à une modification de l'expérience subjective de l'environnement.

Le monde extérieur peut sembler :

  • irréel ;
  • étrange ;
  • distant ;
  • artificiel ;
  • brumeux ;
  • « comme dans un rêve ».

La personne peut généralement savoir que cette impression correspond à une modification de son expérience et non à une transformation réelle du monde.

La déréalisation peut apparaître dans différents contextes, notamment lors d'états de stress important, d'anxiété ou de phénomènes dissociatifs.

1.16 La dépersonnalisation

La dépersonnalisation correspond à une modification de l'expérience subjective de soi.

Une personne peut avoir l'impression :

  • d'être détachée de son propre corps ;
  • d'observer ses actions avec distance ;
  • de fonctionner « automatiquement » ;
  • d'être étrangère à elle-même ;
  • de ne pas ressentir son corps ou ses émotions de manière habituelle.

Comme pour la déréalisation, il peut exister une conscience du caractère inhabituel de l'expérience.

La dépersonnalisation peut être temporaire ou apparaître dans différents contextes psychologiques et médicaux.

1.17 Les hallucinations

Une hallucination correspond à une expérience perceptive vécue comme réelle alors qu'elle ne repose pas sur un stimulus sensoriel externe correspondant.

Elle peut concerner différents sens :

  • visuelle ;
  • auditive ;
  • olfactive ;
  • gustative ;
  • tactile ou somatique.

Les hallucinations peuvent avoir de nombreuses causes possibles.

Elles peuvent notamment apparaître dans certains troubles psychiatriques, certaines maladies neurologiques, lors de consommations ou sevrages de substances, dans certains états médicaux ou lors de certaines transitions entre sommeil et éveil.

Une hallucination n'est donc pas, à elle seule, synonyme de trouble psychiatrique.

1.18 Illusion ou hallucination ?

Ces deux phénomènes sont différents.

Phénomène Stimulus externe correspondant Exemple
Illusion Oui Une ombre interprétée comme une personne
Hallucination Non Percevoir une voix sans source sonore correspondante

La distinction permet de mieux comprendre la différence entre une mauvaise interprétation d'un stimulus et une expérience perceptive sans stimulus externe correspondant.

1.19 Le rôle des attentes dans la perception

Les attentes peuvent influencer ce qui est perçu.

Le cerveau ne traite pas uniquement les informations provenant des sens.

Il utilise également :

  • les expériences précédentes ;
  • les connaissances ;
  • les attentes ;
  • le contexte ;
  • les hypothèses sur ce qui devrait être présent.

Ainsi, deux personnes peuvent parfois interpréter différemment une même situation ambiguë.

1.20 Le rôle du contexte

Une information sensorielle n'est généralement pas interprétée indépendamment de son environnement.

Le contexte peut modifier :

  • l'identification d'un objet ;
  • l'interprétation d'un son ;
  • la reconnaissance d'un visage ;
  • la perception d'une émotion ;
  • la compréhension d'une situation.

Le cerveau cherche constamment à intégrer les différentes informations disponibles pour produire une interprétation cohérente.

1.21 La perception descendante et ascendante

Deux grands types de traitement sont souvent distingués.

Traitement ascendant

Le traitement commence principalement à partir des informations sensorielles.

Les caractéristiques physiques du stimulus sont progressivement analysées.

Traitement descendant

Les connaissances, attentes, expériences et hypothèses influencent l'interprétation des informations sensorielles.

Exemple

Face à une image floue, les connaissances antérieures peuvent aider à identifier ce qui est représenté.

Dans la réalité, ces deux types de traitement fonctionnent généralement ensemble.

1.22 La perception multimodale

La perception multimodale correspond à l'intégration d'informations provenant de plusieurs sens.

Le cerveau peut combiner :

  • la vision ;
  • l'audition ;
  • le toucher ;
  • l'odorat ;
  • les informations corporelles.

Exemple

Pour identifier une personne qui parle, le cerveau peut combiner :

la voix

+

les mouvements du visage

+

le contexte

+

les connaissances sur cette personne.

La perception devient ainsi une expérience intégrée plutôt qu'une simple addition de sensations indépendantes.

1.23 La surcharge sensorielle

La surcharge sensorielle correspond à une situation dans laquelle la quantité ou l'intensité des informations sensorielles devient difficile à traiter ou à supporter.

Elle peut concerner :

  • les sons ;
  • les lumières ;
  • les mouvements ;
  • les odeurs ;
  • le contact physique ;
  • plusieurs stimulations simultanées.

Elle peut s'accompagner de :

  • fatigue ;
  • irritabilité ;
  • difficulté à se concentrer ;
  • besoin de s'isoler ;
  • sentiment de débordement.

La surcharge sensorielle n'est pas un diagnostic en elle-même.

1.24 Pourquoi la perception peut-elle être différente de la réalité physique ?

La perception n'a pas pour objectif de produire une copie parfaite du monde.

Elle permet surtout au cerveau de construire rapidement une représentation suffisamment cohérente pour permettre l'action et l'adaptation.

Cela signifie qu'une perception peut être influencée par :

  • les sens ;
  • l'attention ;
  • la mémoire ;
  • les émotions ;
  • les attentes ;
  • le contexte ;
  • les connaissances ;
  • l'état de vigilance.

Les erreurs perceptives ne signifient donc pas nécessairement que le cerveau « fonctionne mal ».

Certaines sont des conséquences normales du fonctionnement du système perceptif.

1.25 Pourquoi étudier les phénomènes perceptifs ?

L'étude de la perception permet de mieux comprendre :

  • le fonctionnement du cerveau ;
  • les systèmes sensoriels ;
  • l'attention ;
  • l'interprétation des informations ;
  • la conscience ;
  • certains phénomènes cliniques ;
  • les interactions entre perception, mémoire et cognition.

Les phénomènes perceptifs constituent donc un domaine important de la psychologie cognitive, de la psychologie expérimentale et des neurosciences.

À RETENIR

La perception n'est pas une simple copie de la réalité.

Le cerveau sélectionne, organise et interprète continuellement les informations provenant de l'environnement.

Les phénomènes perceptifs montrent notamment que :

  • la perception dépend de l'attention ;
  • les attentes peuvent influencer l'interprétation ;
  • le contexte joue un rôle important ;
  • plusieurs sens peuvent être intégrés simultanément ;
  • certaines erreurs perceptives sont normales ;
  • une perception inhabituelle n'est pas automatiquement pathologique ;
  • les illusions et les hallucinations ne correspondent pas au même phénomène ;
  • la perception est étroitement liée à la mémoire, aux émotions et aux processus cognitifs.

Comprendre la perception permet donc de comprendre comment le cerveau transforme les informations sensorielles en une expérience consciente du monde.
