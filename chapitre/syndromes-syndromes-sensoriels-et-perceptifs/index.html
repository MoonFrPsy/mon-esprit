🧬 Syndromes psychologiques

Syndromes sensoriels et perceptifs

Cette partie regroupe différents phénomènes concernant la manière dont le cerveau reçoit, interprète et organise les informations provenant des sens. Ils peuvent toucher l'ouïe, la vision, le toucher, les mouvements ou plusieurs systèmes sensoriels à la fois.

👂 9.1 La misophonie

🔎 Définition

La misophonie désigne une réaction émotionnelle et physiologique très forte déclenchée par certains sons spécifiques.

Les sons concernés sont généralement des sons répétitifs produits par d'autres personnes.

Il ne s'agit pas simplement de trouver un son désagréable : la réaction peut être disproportionnée par rapport à l'intensité réelle du son.

🔊 Sons fréquemment déclencheurs

Par exemple :

mastication ; déglutition ; respiration ; reniflement ; claquement de lèvres ; tapotements ; clics répétitifs ; bruits de clavier ; certains sons produits avec la bouche.

Les déclencheurs varient fortement d'une personne à l'autre.

🧠 Réactions possibles

Un son déclencheur peut provoquer :

irritation intense ; colère ; anxiété ; dégoût ; tension corporelle ; accélération du rythme cardiaque ; envie de fuir ; difficulté à rester concentré.

🧬 Mécanismes étudiés

Les recherches suggèrent une implication particulière des mécanismes cérébraux permettant d'associer un son à une réaction émotionnelle.

La misophonie pourrait notamment impliquer une interaction inhabituelle entre :

Perception sonore → attention → traitement émotionnel → réaction corporelle

🩺 Diagnostic

La misophonie ne correspond pas simplement à une sensibilité auditive générale.

Son statut diagnostique reste discuté et elle peut être étudiée dans différents contextes cliniques.

📌 À retenir

La misophonie correspond à une réaction extrêmement forte à certains sons spécifiques, souvent répétitifs.

👁️ 9.2 La misokinésie

🔎 Définition

La misokinésie désigne une réaction négative importante déclenchée par l'observation de certains mouvements répétitifs.

Elle peut être considérée comme un phénomène apparenté à la misophonie, mais concernant principalement la vision plutôt que l'audition.

👀 Déclencheurs possibles

Par exemple :

mouvements répétitifs d'une jambe ; tapotements avec les doigts ; mouvements de stylo ; balancement du corps ; agitation répétée ; mouvements de bouche ; gestes répétitifs.

🧠 Réactions

Une personne peut ressentir :

irritation ; tension ; distraction ; anxiété ; colère ; besoin de détourner le regard ; envie d'éviter la situation.

🧩 Particularité

La misokinésie montre que certains phénomènes de sensibilité peuvent être déclenchés non seulement par les sons mais également par des informations visuelles répétitives.

📌 À retenir

Misophonie → sons déclencheurs.

Misokinésie → mouvements visuels déclencheurs.

🔊 9.3 L'hyperacousie

🔎 Définition

L'hyperacousie correspond à une sensibilité anormalement élevée à certains sons ordinaires.

Des sons normalement tolérés peuvent être perçus comme extrêmement forts, désagréables ou douloureux.

🔊 Sons pouvant devenir difficiles

voix ; télévision ; musique ; circulation ; vaisselle ; appareils électroménagers ; bruits de portes ; sons aigus.

🧠 Manifestations

L'hyperacousie peut provoquer :

inconfort ; douleur ; anxiété face aux sons ; évitement des environnements bruyants ; difficulté à supporter certaines activités ; fatigue importante après exposition sonore.

🧬 Causes possibles

Elle peut être associée à :

certaines atteintes auditives ; acouphènes ; migraines ; traumatismes sonores ; certaines maladies neurologiques ; certaines situations médicales.

Elle peut également apparaître sans cause clairement identifiée.

🩺 Diagnostic

Une évaluation médicale ou audiologique peut être réalisée afin d'évaluer la sensibilité auditive et de rechercher une cause.

📌 À retenir

L'hyperacousie concerne principalement l'intensité ou la tolérance aux sons, contrairement à la misophonie qui concerne surtout des sons précis associés à une réaction émotionnelle.

🌈 9.4 La synesthésie

🔎 Définition

La synesthésie est un phénomène perceptif dans lequel une stimulation d'un sens entraîne automatiquement une expérience supplémentaire dans un autre domaine sensoriel ou cognitif.

La personne peut par exemple associer automatiquement :

une lettre à une couleur ; un chiffre à une couleur ; un son à une forme ; une musique à une sensation ; certains mots à des goûts.

🎨 Exemple

Une personne peut toujours percevoir mentalement :

A → rouge

B → bleu

7 → vert

Ces associations sont généralement automatiques et relativement stables.

🧠 Particularités

La synesthésie :

est généralement involontaire ; peut être présente depuis longtemps ; est souvent stable ; n'est pas nécessairement source de souffrance ; n'est pas considérée en ellemême comme une maladie mentale.

🧬 Mécanismes étudiés

Plusieurs hypothèses concernent :

la connectivité entre régions cérébrales ; le traitement multisensoriel ; les mécanismes de perception ; des facteurs génétiques.

📌 À retenir

La synesthésie est principalement un phénomène perceptif et neurocognitif, pas un trouble psychiatrique en soi.

🧠 9.5 La sensibilité sensorielle accrue

🔎 Définition

La sensibilité sensorielle accrue désigne une réaction particulièrement importante à certaines stimulations sensorielles.

Elle peut concerner :

les sons ; la lumière ; les textures ; les odeurs ; le goût ; le toucher ; les mouvements.

👂👁️ Manifestations

Une personne peut être particulièrement sensible :

aux lumières fortes ; aux bruits soudains ; aux vêtements ou tissus ; à certaines textures alimentaires ; aux odeurs ; au contact physique ; à certains environnements très stimulants.

🧩 Contextes possibles

Une sensibilité sensorielle importante peut être observée dans différents contextes :

troubles du neurodéveloppement ; migraines ; anxiété ; stress ; certaines conditions neurologiques ; fatigue ; surcharge sensorielle.

Elle peut également exister sans être liée à un trouble particulier.

📌 À retenir

Une forte sensibilité sensorielle n'est pas automatiquement pathologique. Son importance dépend notamment de son intensité et de ses conséquences sur le fonctionnement quotidien.

👁️ 9.6 Les hallucinations

🔎 Définition

Une hallucination est une expérience perceptive qui survient en l'absence d'une stimulation sensorielle externe correspondante.

Elle peut concerner différents sens.

👁️ Hallucinations visuelles

Perception d'une image, d'une personne, d'un objet ou d'une scène sans stimulus correspondant.

👂 Hallucinations auditives

Perception de sons ou de voix sans source sonore externe correspondante.

👃 Hallucinations olfactives

Perception d'une odeur sans source identifiable.

👅 Hallucinations gustatives

Perception d'un goût sans stimulus correspondant.

✋ Hallucinations tactiles

Sensation de contact ou de mouvement sur le corps sans stimulus externe correspondant.

🧠 Causes possibles

Les hallucinations peuvent être associées à de nombreuses situations :

certains troubles psychiatriques ; troubles neurologiques ; épilepsie ; migraines ; troubles du sommeil ; certaines maladies neurodégénératives ; intoxication ou sevrage de substances ; certains médicaments ; privation sensorielle ; fièvre ou états confusionnels.

🩺 Diagnostic

Le contexte est essentiel.

Une hallucination isolée ne permet pas à elle seule de déterminer l'existence d'un trouble psychiatrique.

L'évaluation cherche notamment à déterminer :

le type d'hallucination ; sa fréquence ; sa durée ; les circonstances ; les autres symptômes ; les éventuelles causes médicales ou neurologiques.

📌 À retenir

Une hallucination est une expérience perceptive sans stimulus externe correspondant. Ses causes sont multiples.

🪞 9.7 Les illusions perceptives

🔎 Définition

Une illusion perceptive correspond à une interprétation erronée ou déformée d'une stimulation réellement présente.

La différence fondamentale avec l'hallucination est donc la présence d'un stimulus externe.

Exemple :

Illusion : un manteau dans une pièce sombre est interprété comme une personne.

Hallucination : perception d'une personne alors qu'aucun objet correspondant n'est présent.

🧠 Types possibles

Les illusions peuvent concerner :

la vision ; l'audition ; le toucher ; l'interprétation de formes ; l'identification d'objets.

🧬 Causes possibles

Elles peuvent apparaître dans des situations normales, notamment :

faible luminosité ; fatigue ; stress ; attention réduite.

Elles peuvent également être observées dans certaines conditions neurologiques ou psychiatriques.

📌 À retenir

Illusion = stimulus réel mal interprété.

Hallucination = perception sans stimulus externe correspondant.

🌀 9.8 La déréalisation

🔎 Définition

La déréalisation correspond à une sensation d'étrangeté ou d'irréalité concernant l'environnement.

Le monde peut sembler :

irréel ; artificiel ; distant ; brumeux ; comme dans un rêve ; « faux » ou inhabituel.

🧠 Manifestations

Une personne peut avoir l'impression :

que les lieux sont étranges ; que les personnes semblent irréelles ; que les couleurs ont changé ; que les sons sont différents ; d'observer le monde comme derrière une vitre ; d'être dans un rêve.

🧩 Contextes possibles

La déréalisation peut être associée à :

stress intense ; anxiété ; attaques de panique ; traumatisme ; fatigue importante ; troubles dissociatifs.

Elle peut également apparaître de manière transitoire.

📌 À retenir

La déréalisation concerne principalement le sentiment de réalité de l'environnement.

🪞 9.9 La dépersonnalisation

🔎 Définition

La dépersonnalisation correspond à une sensation d'étrangeté par rapport à soimême.

Le sentiment d'être soi peut sembler modifié ou distant.

🧠 Manifestations

Une personne peut avoir l'impression :

d'observer son propre corps de l'extérieur ; d'être déconnectée de ses émotions ; que ses pensées ne semblent pas totalement personnelles ; d'agir automatiquement ; que son corps semble étrange ; d'être comme un observateur de soimême.

🧩 Différence avec la déréalisation

Dépersonnalisation : sentiment d'irréalité concernant soimême.

Déréalisation : sentiment d'irréalité concernant l'environnement.

Les deux peuvent apparaître simultanément.

📌 À retenir

La dépersonnalisation concerne principalement l'expérience subjective de soi.

🔄 9.10 La surcharge sensorielle

🔎 Définition

La surcharge sensorielle survient lorsque la quantité ou l'intensité des stimulations reçues devient difficile à traiter.

Le cerveau reçoit alors davantage d'informations sensorielles qu'il ne parvient efficacement à organiser à ce momentlà.

🔊 Stimulations possibles

bruit ; lumière ; foule ; conversations multiples ; odeurs ; mouvements ; contacts physiques ; informations visuelles nombreuses.

🧠 Manifestations

Elle peut provoquer :

fatigue ; irritabilité ; difficulté à réfléchir ; besoin de s'isoler ; anxiété ; sensation d'être submergé ; difficulté à communiquer ; baisse de concentration.

🧩 Contextes possibles

La surcharge sensorielle peut apparaître dans différents contextes et n'est pas spécifique à un seul trouble.

Elle peut notamment être favorisée par :

fatigue ; stress ; environnement très stimulant ; certaines particularités neurodéveloppementales ; certaines migraines ; certaines conditions neurologiques.

📌 À retenir

La surcharge sensorielle correspond à une difficulté temporaire ou répétée à traiter un volume important de stimulations sensorielles.

🧠 À RETENIR PARTIE 9

La perception n'est pas une simple reproduction du monde extérieur. Le cerveau sélectionne, organise et interprète constamment les informations provenant des sens.

Une modification de ce fonctionnement peut concerner :

👂 L'audition

→ misophonie, hyperacousie.

👁️ La vision

→ misokinésie, illusions perceptives.

🌈 Plusieurs sens

→ synesthésie, surcharge sensorielle.

🧠 La perception du réel

→ déréalisation.

🪞 La perception de soi

→ dépersonnalisation.

👁️👂 Les expériences perceptives sans stimulus correspondant

→ hallucinations.
