🩺 Troubles psychologiques

Partie 19 — Troubles liés à des affections médicales

🧠 19.1 Qu'est-ce qu'un trouble mental dû à une affection médicale ?

Définition

Un trouble mental dû à une affection médicale correspond à des symptômes psychologiques ou comportementaux qui peuvent être directement liés aux conséquences physiologiques d'une maladie ou d'une autre affection médicale.

Manifestations possibles

  • changements émotionnels ;
  • anxiété ;
  • dépression ;
  • confusion ;
  • changements de personnalité ;
  • difficultés cognitives ;
  • comportements inhabituels.

À retenir

Une maladie physique peut parfois avoir des conséquences importantes sur le fonctionnement psychologique.

🧠 19.2 Le lien entre cerveau et corps

Définition

Le fonctionnement psychologique dépend du fonctionnement du cerveau et de l'ensemble de l'organisme.

Une affection médicale peut donc modifier indirectement ou directement :

  • les émotions ;
  • la mémoire ;
  • l'attention ;
  • le comportement ;
  • le sommeil ;
  • la personnalité.

À retenir

La santé physique et la santé mentale sont étroitement liées.

🧠 19.3 Les symptômes psychiatriques secondaires

Définition

Un symptôme psychiatrique secondaire est un symptôme psychologique apparaissant dans le contexte d'une autre affection médicale.

Exemples

Une maladie peut être associée à :

  • anxiété ;
  • irritabilité ;
  • apathie ;
  • dépression ;
  • confusion ;
  • hallucinations.

À retenir

Le contexte médical est essentiel pour comprendre l'origine possible des symptômes.

🧠 19.4 Le trouble neurocognitif dû à une affection médicale

Définition

Certaines affections médicales peuvent entraîner une diminution des capacités cognitives.

Fonctions pouvant être touchées

  • mémoire ;
  • attention ;
  • langage ;
  • raisonnement ;
  • orientation ;
  • fonctions exécutives.

À retenir

Ces troubles sont étudiés plus précisément dans la partie consacrée aux troubles neurocognitifs.

🧠 19.5 Les maladies neurologiques

Définition

Les maladies neurologiques touchent le système nerveux et peuvent parfois provoquer des changements psychologiques ou comportementaux.

Exemples

  • épilepsie ;
  • maladie de Parkinson ;
  • sclérose en plaques ;
  • accidents vasculaires cérébraux ;
  • traumatismes cérébraux.

🧠 19.6 Les traumatismes cérébraux

Définition

Un traumatisme crânien peut entraîner des modifications du fonctionnement cérébral.

Conséquences possibles

  • difficultés de mémoire ;
  • troubles de l'attention ;
  • irritabilité ;
  • impulsivité ;
  • changements émotionnels ;
  • difficultés de planification.

À retenir

Les conséquences dépendent notamment de la gravité et de la localisation de la lésion.

🧠 19.7 L'accident vasculaire cérébral

Définition

Un AVC survient lorsque l'apport sanguin à une partie du cerveau est interrompu ou lorsqu'un vaisseau sanguin se rompt.

Conséquences psychologiques possibles

  • dépression ;
  • anxiété ;
  • changements émotionnels ;
  • difficultés cognitives ;
  • changements de comportement.

🧠 19.8 L'épilepsie et la psychologie

Définition

L'épilepsie est une affection neurologique caractérisée par une prédisposition à présenter des crises épileptiques.

Conséquences possibles

Certaines personnes peuvent présenter :

  • anxiété ;
  • dépression ;
  • difficultés cognitives ;
  • fatigue ;
  • changements émotionnels.

À retenir

Ces symptômes peuvent également être influencés par les traitements, les crises ou les conséquences sociales de la maladie.

🧠 19.9 La maladie de Parkinson

Définition

La maladie de Parkinson est une maladie neurologique progressive qui affecte notamment les mouvements.

Manifestations psychologiques possibles

  • dépression ;
  • anxiété ;
  • apathie ;
  • troubles cognitifs ;
  • troubles du sommeil ;
  • changements comportementaux.

🧠 19.10 La sclérose en plaques

Définition

La sclérose en plaques est une maladie inflammatoire du système nerveux central.

Conséquences psychologiques possibles

  • fatigue ;
  • difficultés cognitives ;
  • dépression ;
  • anxiété ;
  • changements émotionnels.

À retenir

Les symptômes psychologiques peuvent être liés à la maladie elle-même ou à ses conséquences.

🧠 19.11 Les maladies endocriniennes

Définition

Les maladies endocriniennes concernent les hormones et les glandes qui les produisent.

Exemples

  • troubles thyroïdiens ;
  • troubles des glandes surrénales ;
  • troubles hormonaux.

Conséquences psychologiques possibles

  • fatigue ;
  • irritabilité ;
  • anxiété ;
  • changements de l'humeur ;
  • difficultés de concentration.

🧠 19.12 Les troubles de la thyroïde

Définition

La thyroïde produit des hormones qui participent notamment à la régulation du métabolisme.

Conséquences possibles

Un dérèglement peut être associé à :

  • fatigue ;
  • nervosité ;
  • ralentissement psychique ;
  • troubles de l'humeur ;
  • difficultés de concentration.

🧠 19.13 Les maladies auto-immunes

Définition

Une maladie auto-immune survient lorsque le système immunitaire attaque anormalement certaines cellules ou certains tissus de l'organisme.

Conséquences psychologiques possibles

Selon la maladie :

  • fatigue ;
  • douleurs ;
  • anxiété ;
  • dépression ;
  • difficultés cognitives.

🧠 19.14 Les maladies chroniques

Définition

Une maladie chronique est une affection qui persiste dans le temps.

Impact psychologique

Vivre avec une maladie chronique peut entraîner :

  • stress ;
  • anxiété ;
  • découragement ;
  • tristesse ;
  • difficultés d'adaptation.

À retenir

La présence d'une maladie chronique ne signifie pas automatiquement qu'un trouble psychiatrique est présent.

🧠 19.15 La douleur chronique

Définition

La douleur chronique correspond à une douleur persistante ou récurrente sur une longue période.

Conséquences psychologiques possibles

  • fatigue ;
  • irritabilité ;
  • troubles du sommeil ;
  • anxiété ;
  • humeur dépressive ;
  • difficultés de concentration.

🧠 19.16 Les maladies cardiovasculaires

Définition

Les maladies cardiovasculaires concernent le cœur et les vaisseaux sanguins.

Conséquences psychologiques possibles

Certaines personnes peuvent présenter :

  • anxiété ;
  • peur d'une nouvelle crise ;
  • humeur dépressive ;
  • stress.

🧠 19.17 Les maladies respiratoires

Définition

Certaines maladies respiratoires chroniques peuvent avoir des conséquences psychologiques.

Manifestations possibles

  • anxiété ;
  • peur de manquer d'air ;
  • fatigue ;
  • diminution des activités ;
  • humeur dépressive.

🧠 19.18 Les maladies métaboliques

Définition

Les maladies métaboliques peuvent modifier différents mécanismes biologiques de l'organisme.

Conséquences possibles

Selon la maladie :

  • fatigue ;
  • difficultés de concentration ;
  • changements d'humeur ;
  • troubles cognitifs.

🧠 19.19 Le diabète et la santé mentale

Définition

Le diabète est une maladie chronique affectant notamment la régulation du glucose dans le sang.

Conséquences psychologiques possibles

  • stress lié à la maladie ;
  • anxiété ;
  • fatigue ;
  • humeur dépressive ;
  • difficultés d'adaptation.

À retenir

La gestion quotidienne d'une maladie chronique peut représenter une charge psychologique importante.

🧠 19.20 Les maladies infectieuses

Définition

Certaines infections peuvent avoir des conséquences neurologiques ou psychologiques.

Manifestations possibles

Selon l'infection :

  • confusion ;
  • fatigue ;
  • troubles cognitifs ;
  • changements comportementaux ;
  • troubles de l'humeur.

🧠 19.21 Les infections touchant le cerveau

Définition

Certaines infections peuvent directement affecter le cerveau ou ses membranes.

Conséquences possibles

  • confusion ;
  • troubles de mémoire ;
  • changements de comportement ;
  • troubles de la conscience ;
  • symptômes neurologiques.

À retenir

Ces situations nécessitent une prise en charge médicale.

🧠 19.22 Les troubles hormonaux et l'humeur

Définition

Les hormones participent à de nombreux mécanismes physiologiques et peuvent influencer l'énergie et l'humeur.

Manifestations possibles

  • irritabilité ;
  • fatigue ;
  • changements de l'humeur ;
  • difficultés de concentration.

🧠 19.23 Les troubles neurologiques et la personnalité

Définition

Certaines lésions ou maladies neurologiques peuvent modifier certains aspects du comportement ou de la personnalité.

Manifestations

  • impulsivité ;
  • irritabilité ;
  • apathie ;
  • désinhibition ;
  • diminution de l'empathie.

À retenir

Ces changements ne sont pas nécessairement volontaires.

🧠 19.24 Les changements de comportement dus à une affection médicale

Définition

Certaines affections médicales peuvent entraîner des modifications importantes du comportement.

Exemples

  • agressivité inhabituelle ;
  • impulsivité ;
  • désinhibition ;
  • apathie ;
  • comportements répétitifs.

🧠 19.25 L'apathie

Définition

L'apathie correspond à une diminution importante de la motivation ou de l'intérêt.

Manifestations

  • manque d'initiative ;
  • diminution des activités ;
  • indifférence apparente ;
  • réduction des interactions sociales.

À retenir

L'apathie peut être associée à certaines maladies neurologiques.

🧠 19.26 La désinhibition

Définition

La désinhibition correspond à une diminution du contrôle habituel des comportements.

Manifestations possibles

  • comportements impulsifs ;
  • paroles inappropriées ;
  • prise de risques ;
  • difficulté à respecter certaines règles sociales.

À retenir

Une désinhibition inhabituelle peut avoir une origine neurologique ou médicale.

🧠 19.27 Les troubles de l'humeur secondaires

Définition

Certaines affections médicales peuvent provoquer des symptômes ressemblant à ceux d'un trouble de l'humeur.

Manifestations

  • tristesse ;
  • perte d'intérêt ;
  • irritabilité ;
  • fatigue ;
  • changements du sommeil.

À retenir

Il est important de rechercher une cause médicale lorsqu'elle est possible.

🧠 19.28 Les symptômes dépressifs secondaires

Définition

Une maladie physique peut être associée à des symptômes dépressifs.

Manifestations

  • tristesse ;
  • perte d'intérêt ;
  • fatigue ;
  • troubles du sommeil ;
  • difficultés de concentration.

À retenir

Un professionnel doit déterminer si les symptômes correspondent à un trouble dépressif ou s'ils sont principalement liés à l'affection médicale.

🧠 19.29 Les symptômes anxieux secondaires

Définition

Certaines affections médicales peuvent provoquer ou favoriser des symptômes anxieux.

Manifestations

  • inquiétude ;
  • agitation ;
  • tension ;
  • peur ;
  • difficultés de sommeil.

🧠 19.30 Les symptômes psychotiques secondaires

Définition

Certaines affections médicales peuvent provoquer des symptômes psychotiques.

Manifestations possibles

  • hallucinations ;
  • idées délirantes ;
  • désorganisation de la pensée ;
  • comportement inhabituel.

À retenir

Une apparition soudaine de symptômes psychotiques nécessite une évaluation médicale afin de rechercher notamment une cause physique ou liée à une substance.

🧠 19.31 Les hallucinations dues à une affection médicale

Définition

Une hallucination correspond à une perception vécue comme réelle alors qu'aucun stimulus externe correspondant n'est présent.

Causes médicales possibles

Certaines maladies neurologiques, infections, troubles métaboliques ou autres affections peuvent être impliqués.

🧠 19.32 Les troubles de la conscience

Définition

Certaines affections médicales peuvent modifier le niveau de conscience ou la capacité à interagir normalement avec l'environnement.

Manifestations

  • confusion ;
  • somnolence ;
  • désorientation ;
  • diminution de la vigilance.

🧠 19.33 Le délirium

Définition

Le délirium est un état aigu caractérisé notamment par une perturbation de l'attention et de la conscience, accompagné de changements cognitifs.

Causes possibles

  • infections ;
  • médicaments ;
  • troubles métaboliques ;
  • intoxication ou sevrage ;
  • maladies neurologiques.

À retenir

Le délirium constitue une situation médicale nécessitant une évaluation rapide.

🧠 19.34 Les troubles du sommeil liés aux maladies

Définition

Certaines maladies peuvent perturber le sommeil.

Manifestations

  • difficultés d'endormissement ;
  • réveils fréquents ;
  • somnolence ;
  • sommeil non réparateur.

À retenir

Les troubles du sommeil peuvent ensuite aggraver la fatigue et les difficultés psychologiques.

🧠 19.35 La fatigue liée aux affections médicales

Définition

La fatigue peut être un symptôme direct d'une maladie ou de son traitement.

Conséquences

Elle peut affecter :

  • concentration ;
  • motivation ;
  • humeur ;
  • activité physique ;
  • vie sociale.

🧠 19.36 Les médicaments et les symptômes psychologiques

Définition

Certains médicaments peuvent provoquer ou modifier certains symptômes psychologiques.

Manifestations possibles

  • somnolence ;
  • agitation ;
  • anxiété ;
  • troubles cognitifs ;
  • changements de l'humeur.

À retenir

Il ne faut pas arrêter ou modifier un traitement sans avis médical.

🧠 19.37 Les effets secondaires neurologiques

Définition

Certains traitements peuvent influencer le fonctionnement du système nerveux.

Conséquences possibles

  • difficultés de concentration ;
  • somnolence ;
  • tremblements ;
  • changements émotionnels ;
  • confusion.

🧠 19.38 L'effet des substances sur le fonctionnement psychologique

Définition

L'alcool, certaines drogues et certains médicaments peuvent modifier le fonctionnement cérébral.

Conséquences possibles

  • changements de l'humeur ;
  • anxiété ;
  • confusion ;
  • troubles de la perception ;
  • impulsivité.

🧠 19.39 Le diagnostic

Définition

Le diagnostic cherche à déterminer si les symptômes psychologiques sont directement liés à une affection médicale.

Éléments étudiés

  • histoire médicale ;
  • apparition des symptômes ;
  • évolution ;
  • médicaments ;
  • examens médicaux ;
  • fonctionnement psychologique.

🧠 19.40 Le diagnostic différentiel

Définition

Le diagnostic différentiel permet de distinguer plusieurs causes possibles.

Causes pouvant être étudiées

  • trouble psychiatrique primaire ;
  • affection médicale ;
  • médicament ;
  • substance ;
  • stress ;
  • trouble neurologique.

🧠 19.41 L'importance de la chronologie

Définition

La chronologie permet d'étudier la relation entre la maladie et les symptômes psychologiques.

Exemple

Si un changement comportemental apparaît rapidement après une lésion cérébrale, le professionnel cherchera notamment à déterminer si les deux événements sont liés.

🧠 19.42 Les examens médicaux

Définition

Selon la situation, différents examens peuvent être utilisés.

Exemples

  • analyses biologiques ;
  • imagerie cérébrale ;
  • examens neurologiques ;
  • examens hormonaux ;
  • évaluations cognitives.

À retenir

Les examens dépendent des symptômes et de la maladie suspectée.

🧠 19.43 L'évaluation neuropsychologique

Définition

L'évaluation neuropsychologique permet d'étudier différentes fonctions cognitives.

Fonctions étudiées

  • mémoire ;
  • attention ;
  • langage ;
  • raisonnement ;
  • fonctions exécutives ;
  • vitesse de traitement.

🧠 19.44 La prise en charge

Définition

La prise en charge dépend principalement de la cause des symptômes.

Approches possibles

  • traitement de la maladie sous-jacente ;
  • adaptation des médicaments ;
  • psychothérapie ;
  • rééducation cognitive ;
  • accompagnement familial ;
  • traitement psychiatrique lorsque nécessaire.

🧠 19.45 La rééducation cognitive

Définition

La rééducation cognitive vise à aider une personne à récupérer ou compenser certaines difficultés cognitives.

Objectifs

  • améliorer certaines fonctions ;
  • développer des stratégies compensatoires ;
  • favoriser l'autonomie ;
  • adapter l'environnement.

🧠 19.46 La psychothérapie

Définition

La psychothérapie peut aider une personne à gérer les conséquences psychologiques d'une affection médicale.

Objectifs

  • mieux comprendre la situation ;
  • gérer l'anxiété ;
  • s'adapter aux changements ;
  • travailler sur l'humeur ;
  • améliorer les stratégies d'adaptation.

🧠 19.47 L'accompagnement familial

Définition

Une maladie peut affecter non seulement la personne malade, mais également son entourage.

Objectifs

  • comprendre les changements ;
  • adapter la communication ;
  • réduire les conflits ;
  • soutenir l'autonomie ;
  • aider les proches à mieux gérer la situation.

🧠 19.48 L'adaptation psychologique à la maladie

Définition

L'adaptation psychologique correspond au processus permettant à une personne de s'adapter aux changements provoqués par une maladie.

Réactions possibles

  • peur ;
  • colère ;
  • tristesse ;
  • déni ;
  • acceptation progressive ;
  • recherche de nouvelles stratégies.

À retenir

Les réactions varient fortement d'une personne à l'autre.

🧠 19.49 Quand consulter ?

Une consultation peut être nécessaire lorsqu'apparaissent :

  • changement soudain de personnalité ;
  • confusion ;
  • hallucinations ;
  • troubles importants de mémoire ;
  • changement brutal du comportement ;
  • symptômes dépressifs importants ;
  • anxiété inhabituelle ;
  • difficultés cognitives nouvelles.

À retenir

Un changement psychologique soudain peut parfois avoir une cause médicale et mérite donc une évaluation adaptée.

🧠 19.50 Comprendre le lien entre maladie et psychologie

Définition

Une affection médicale peut avoir des conséquences psychologiques, tout comme l'état psychologique peut influencer la manière dont une personne vit sa maladie.

À retenir

Il est important de considérer la personne dans son ensemble :

Corps + cerveau + émotions + environnement + relations.

Une maladie physique ne signifie pas automatiquement qu'une personne développe un trouble psychiatrique, et un symptôme psychologique ne signifie pas nécessairement qu'il existe une maladie physique.
